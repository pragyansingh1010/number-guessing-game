# Number Guessing Game — QA Checklist

- Test guesses below, equal to, and above the target.
- Reject blank, non-numeric, and out-of-range guesses.
- Confirm attempt count increments only for valid guesses.
- Ensure a new round resets attempts and feedback.
- Prevent further guesses after the correct answer until restart.
- Check that feedback is understandable using keyboard-only navigation.
